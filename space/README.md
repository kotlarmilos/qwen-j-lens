# Qwen J-lens Artifact Viewer

This Space reads uploaded result artifacts only. It does not download or run a
language model. It recursively verifies referenced arrays and SHA-256 digests.
Missing or corrupt files are listed explicitly.

Expected project links are the
[article](https://github.com/kotlarmilos/qwen-j-lens/blob/main/article.md),
[repository](https://github.com/kotlarmilos/qwen-j-lens),
[artifact card](https://huggingface.co/kotlarmilos/qwen-j-lens), and
[dataset card](https://huggingface.co/datasets/kotlarmilos/qwen-j-lens-evaluation).
