# Qwen J-lens evaluation prompts

## Description

`data/evaluation_prompts.jsonl` is a small, hand-authored evaluation set for
paired controlled-token experiments. It is a protocol fixture, not a benchmark
with validated population-level coverage.

## Schema

Each row contains `id`, `property`, `prompt`, `target_concepts`, and optional
`control_prompt`, `measurement_steps`, and `intervention` fields. Allowed properties are
`verbal_report`, `directed_modulation`, `internal_reasoning`, and
`selectivity`.

Evaluation outputs follow `EVALUATION_RESULT_SCHEMA` in
`src/qwen_j_lens/evaluation.py`. Every result records raw activation
trajectories, preregistered measurement steps, signed target and control
effects, and consistently absolute target and control damage.

## Collection

The prompts were written for this project. They contain no scraped personal
data and no model-generated labels. The smoke calibration corpus is stored in
`data/calibration_prompts.jsonl`. The publication configuration uses a
deterministic 1,000-context sample from the pinned `Salesforce/wikitext`
`wikitext-2-raw-v1` training split, generated by
`scripts/prepare_publication_corpus.py`. WikiText is licensed under CC BY-SA
3.0 and GFDL. The smaller, encyclopedic source is less diverse than the source
paper's distribution and is a declared methodological deviation.

## Recommended protocol

Use raw calibration tokenization and Qwen's chat template for evaluation.
Record surface-generation activation trajectories. Score directed modulation
across those trajectories and internal reasoning only at preregistered steps.
Evaluate concept swaps against same-category alternatives. Compare
controlled-subset ablation on reasoning tasks with routine grammar, copying,
and fluency controls. Report failures and uncertainty rather than filtering
inconvenient runs.

## Limitations

The set is small and English-only. Keyword scores are insufficient by
themselves and require blinded manual review. Prompt sensitivity and token
boundary effects can dominate small samples. Results test functional workspace
properties and do not establish consciousness.
